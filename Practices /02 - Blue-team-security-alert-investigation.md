# Blue Team Fundamentals: Security Alert Investigation & Incident Response

## Overview
This project documents a hands-on defensive cybersecurity lab focused on identifying, investigating and responding to suspicious activities within a simulated security environment.

The exercise demonstrates how security defenders monitor alerts, identify potential threats and implement defensive controls to prevent unauthorised access.

## Objectives
- Understand how to monitor a security dashboard.
- Review and identify suspicious security alerts.
- Investigate potentially malicious IP addresses.
- Identify suspicious activities targeting administrative pages.
- Apply defensive measures to contain and mitigate threats.
- Enable security controls to prevent further attacks.
